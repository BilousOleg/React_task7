1. Реалізувати картку користувача (товару). Стан зберігати в глобальному сховищі store.
   При натисканні на іконку сердечка додавати/прибирати користувача (товар) з улюбленого (міняти isFavourite на протилежне).

2. Реалізувати картку з погодою. Дані зберігати в сторі.
   Дані зберігаються у вказаних одиницях (градуси Цельсія, кілометри на годину). Передбачити можливість змінювати одиниці виміру

- 'celsius' на 'fahrenheit' (градуси по Фаренгейту) і навпаки,

- 'kmh' на 'ms' (метри на секунду) і навпаки

  за стандартними формулами.
